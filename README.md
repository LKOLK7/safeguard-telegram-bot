
# Safeguard Bot (Telegram)

A production‑ready Telegram moderation & security bot. It provides smart anti‑spam, link safety checks, file malware scanning, toxicity screening, and CAPTCHA‑based verification designed for classrooms and communities.

## ✨ Features

- **Join verification**: Post‑join CAPTCHA in groups and pre‑join deep‑link CAPTCHA for join requests. Users must pass before chatting. 
- **Link safety (optional)**: Google Safe Browsing & VirusTotal checks for non‑Telegram links; severity‑based auto‑mitigation (delete/mute/warn). 
- **File scanning (optional)**: Uploads documents/photos to VirusTotal, shows top‑engine verdicts, and can forward malicious files to a private **Vault** channel with an HTML report. 
- **Flood control**: Message‑rate limiter with temporary mute. 
- **Offensive word filter**: Configurable allowlist/denylist with `/addbadword` & `/removebadword`. 
- **AI toxicity screening (optional)**: Google Perspective API (TOXICITY, SEVERE_TOXICITY, INSULT, THREAT). 
- **Admin utilities**: `/ping`, `/diagnose`, `/togglelinks`, `/function`, `/rules`, `/report`, `/warnings`. 
- **Ephemeral bot messages**: Auto‑delete helper to keep groups clean (configurable TTL).
